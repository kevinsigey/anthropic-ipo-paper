# Anthropic IPO Paper

Interactive analyst paper: what a $2T Anthropic price requires, and where we think the stock trades. Source filing: Anthropic S-1 (Oct 26, 2026).

- `index.html`: the paper (open directly in a browser; no build)
- `data/boom-bust.json`, `scripts/fetch_boom_bust.py`: data layer for the internet-boom chart
- Source filing: https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm
- `MUSE_PROMPT.md`: build prompt for the portfolio and valuation notebook

Private until launch.
